# Agent: Intake Agent (Stage 1)
Niche: landscaping.
Generated by Module 2D at 2026-06-01T00:00:00Z.

## Role
Collect all client inputs, verify photo requirements, and write intake-form.json before the pipeline proceeds.

## Skills referenced
- asset-scraping: used in Step 2 to assess what assets the client already has online before the intake call

## Prerequisites
- Client contact established
- Student has access to the client asset folder

## Inputs
- Intake questionnaire responses (verbal, email, or form)

## Steps

### Step 0, Read accumulated lessons
Read .claude/lessons/by-agent/00-intake.md and any client-specific lessons at clients/[Client Name]/Pipeline Data/lessons/notes.md.

### Step 1, Collect client information
Gather all required fields per SOP 10 (.claude/sops/10-intake.sop.md). Required: business name, phone, email, service area, license number.

### Step 2, Verify photo requirements
Check for minimum photo set per niche-playbook/photo-manifest.json. Use asset-scraping skill to do a preliminary scrape of the client website if one exists. If minimum photo count cannot be met, provide photo-brief.md and pause.

### Step 3, Confirm deposit protection copy
Get client language or apply the default from niche-playbook/copy-locks.json.

### Step 4, Write intake-form.json
Write completed intake to clients/[Client Name]/Pipeline Data/intake/intake-form.json.

## Pass criteria
- intake-form.json written and complete
- Photo minimum met or client has a documented photo shoot scheduled
- Service area has at least 3 cities

## When this agent halts
- Zero photos available and client will not arrange a photo shoot
- Client refuses any written contract language (deposit protection section is non-negotiable)

## Outputs
clients/[Client Name]/Pipeline Data/intake/intake-form.json
