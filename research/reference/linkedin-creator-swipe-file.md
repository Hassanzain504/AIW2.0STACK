# LinkedIn Creator Swipe File

Reference material for the student's own content engine (Module 7, `/generate-ce-brief`).

This file covers two things:

1. Every content format LinkedIn actually supports, and which ones still get reach.
2. Named creators who publish informational content, what each one is worth studying for, and their verified profile.

Scope note: this is for the **student's own lead generation**, not a client deliverable. The
content engine exists to pull inbound leads so the student does not have to grind cold DMs.
Clients never see it.

Last verified: 2026-09-02.

---

## Part 1: Native formats

These are the post types LinkedIn itself supports.

| Format | What it is | Notes |
|---|---|---|
| Text post | Text only, no media | Oldest format, still one of the highest-reach options |
| Document post (carousel) | PDF upload rendered as swipeable slides | Creators call it a carousel, LinkedIn calls it a document post |
| Native video | Video uploaded directly to LinkedIn | Far more reach than posting a YouTube link |
| Short-form vertical video | LinkedIn's own vertical video feed | Properly rolled out from 2024 onward |
| Image post | Single image, or up to 20 images in one post | |
| Poll | 2 to 4 options, runs 1 day to 2 weeks | |
| Article | Long-form, lives permanently on the profile | |
| Newsletter | Subscribable series, notifies subscribers per issue | Strongest owned-audience tool on the platform |
| Live | Live stream from a profile or page | |
| Event | Online or offline event page with registration | |
| Repost with thoughts | Someone else's post plus your commentary | |
| Collaborative article | Contribution to LinkedIn's AI-generated topic prompts | Source of the "Top Voice" badge |
| Featured section | Pinned posts, links, and media on the profile | |

### Formats that no longer work

- **Stories** were discontinued in 2021.
- **Creator Mode** was retired in 2023. Its features (Follow button, Featured section) are now default for everyone.
- **Engagement pods** are actively penalised. Reach drops and accounts risk restriction.

## Part 2: Content styles

These are the writing and structuring patterns creators apply on top of the formats.

| Style | What it is |
|---|---|
| Hook post | First two lines carry the whole post, written to earn the "see more" click |
| Broetry | One line per paragraph. LinkedIn's signature style, now somewhat overused |
| Storytelling post | Personal story leading to a lesson. Struggle, turning point, takeaway |
| Contrarian take | Challenges a common industry belief. Biggest driver of comments |
| Listicle | "7 things I learned". Easy to scan |
| Framework post | A named, repeatable system. Builds authority faster than one-off tips |
| Case study | One client, one result, real numbers. Strongest format for agency owners |
| Build in public | Revenue, failures, and live progress shared openly |
| Teardown | Public analysis of a website, ad, or brand. Pairs best with a carousel |
| Screenshot post | Proof: DM replies, dashboards, client messages |
| Myth busting | "These 5 things are wrong" |
| Before and after | Visual proof. Ideal for website redesigns |
| Infographic carousel | Data or process broken into visual slides |
| Milestone post | Achievement announcement. High reach, low lead quality |
| Selfie post | Face photo. Face detection lifts reach |
| Comment marketing | Thoughtful comments on other people's large posts rather than your own. Fastest growth lever for a new account |
| Collab post | Tagging another creator to reach their audience |
| Repurposed clip | 30 to 60 second cuts from a longer video, with captions |

## Part 4: How to use this file

Following these creators is worth nothing on its own. The value is in extracting the pattern
and transplanting it into the student's niche.

1. Pull each creator's top 20 posts. Use the Featured section on their profile, and sort their
   activity feed by Top.
2. For each post, record three things: the format used, the exact first line, and the structural
   skeleton of the body.
3. Rewrite that skeleton for the chosen niche.

Worked example, assuming the niche is roofers:

- Josh Braun's cold DM breakdown format, rewritten for outreach to roofing company owners.
- Katelyn Bourgoin's buyer-psychology carousel, rewritten for the homeowner staring at a
  $15k roof quote.
- Tom Boston's native video approach, rewritten as short clips about what a bad roofing
  website costs a roofer in lost calls.

The output of step 3 is exactly the input that `/generate-ce-brief` expects for the content
buckets. Do not fill this in before `m2c.nicheDecided` is true. Without a locked niche there is
nothing concrete to rewrite the skeletons against.
