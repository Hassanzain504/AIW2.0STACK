# Wolf Contractor SEO

Complete SEO plan for the Wolf Contractor brand website (the agency that sells websites and
marketing to window cleaning and exterior cleaning businesses; competitor to Contractor
Gorilla).

## Files

- `Wolf-Contractor-SEO-Playbook.md` — the full plan. Read this. It covers positioning and
  competitor analysis, keyword strategy, site architecture, on-page SEO per page, technical
  SEO, local SEO and Google Business Profile, backlinks, the blog content engine, conversion,
  AI ranking (AEO/GEO for ChatGPT, Perplexity, Google AI Overviews), measurement, and a
  90-day week-by-week action plan.
- `keyword-map.csv` — every target keyword with intent, target URL, and priority. Import
  straight into Ahrefs, Semrush, or a sheet and start rank tracking.

## Where to start

1. Open the playbook, go to Section 12 (the 90-day action plan), and work top to bottom.
2. Import `keyword-map.csv` into your rank tracker.
3. If you have a live domain, send it over for a page-by-page audit against Section 4.

## Assumptions (correct if wrong)

- Market: United States.
- Positioning: window / exterior cleaning specialist first, broader trades later.
- Site treated as build-from-scratch or full rebuild, so every spec is rank-ready on launch.
