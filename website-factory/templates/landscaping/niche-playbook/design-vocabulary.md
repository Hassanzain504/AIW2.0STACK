# Design Vocabulary - Landscaping Niche

Extracted from the top-scoring sites in the niche analysis (sweeneyslandscaping.com, iamgreenwise.com, marktessier.com).

## Layout patterns observed

**Hero patterns:**
- Full-bleed photo with text overlay (all 3 top sites)
- Centered content with dual CTAs (sweeneyslandscaping.com primary pattern)
- Trust bar or stat row below the CTA buttons

**Section alternation:**
- Neutral background (#F7F5F0 or similar warm off-white) alternates with white
- No dark sections except footer
- Accent color used sparingly for CTAs and icon fills

**Gallery patterns:**
- Grid layout (3 columns desktop, 2 tablet, 1 mobile)
- Filter tabs above the grid
- Card-based items with photo top, metadata below
- Before/after pairs labeled explicitly

## Typography signals

**From iamgreenwise.com:** Clean sans-serif body, moderate heading hierarchy. Professional without being corporate.
**From marktessier.com:** Serif or high-quality display font for headings. Communicates craft and permanence.
**Template decision:** Playfair Display for headings (craft, longevity), Inter for body (clean, readable).

## Color signals

All top sites use green as primary. iamgreenwise.com uses a sage green accent. sweeneyslandscaping.com uses a darker forest green. Template synthesizes both: deep forest green primary (#2D5016), sage green accent (#8B9E3A).

Warm neutrals for backgrounds. None of the top sites use cool grays.

## Component patterns

**CTA buttons:** Rounded corners (8px), adequate padding (16px vertical), minimum 48px height.
**Cards:** Light shadow, rounded corners, clean border or none.
**Badge/guarantee sections:** Centered, prominent, with an icon or badge image.
**Team photos:** Circular or softly rounded, outdoor setting.

## What to avoid

- Aggressive diagonal section dividers
- Neon or saturated accent colors
- Heavy drop shadows
- Stock photography
- Dense text blocks without breathing room
